


UNIVERSITY COURSE FINDER – INTELLIGENT COURSE 
DISCOVERY SYSTEM 
Overview 
Students often struggle to identify the right online courses based on their learning goals, 
existing skills, preferred difficulty level, and career objectives. Traditional course search 
systems generally rely on keywords and may return large numbers of courses without 
understanding the student's actual intent. 
Students may ask questions such as: 
• “I want to learn data science from the basics. Which courses should I start with?”  
• “I know Python and SQL. What courses should I take next to move into machine 
learning?”  
• “I want to learn cloud computing but I don't know which prerequisite courses I need.”  
• “Can you suggest a learning path from beginner to advanced data analytics?”  
Instead of relying only on keyword-based search, the system should understand the student's 
learning goal, identify relevant courses, analyze skill gaps and prerequisites, and recommend a 
suitable learning path. 
Build an intelligent course discovery system that allows students to enter natural-language 
learning goals and retrieve relevant courses along with skill-gap analysis, prerequisite 
information and personalized learning-path recommendations.

Task Details 
Task 1 – Course Data Preparation & Knowledge Base 
• Prepare the provided course dataset for intelligent retrieval and recommendation.  
• The task should result in a searchable course knowledge base containing course 
descriptions, skills and relevant metadata.  
• Document the preprocessing, embedding and indexing approach used. 
Task 2 – Semantic Course Search & Recommendation 
• Build the core course discovery capability. A student should be able to enter a natural
language learning goal and receive relevant courses.  
• The system should use semantic or hybrid retrieval, support appropriate filters and 
provide an explanation for the recommended courses. 
Task 3 – Skill Gap, Prerequisite & Learning Path Analysis 
• Extend the basic recommendation system by analyzing the student's skill requirements 
and prerequisites.  
• The solution should identify missing skills and recommend suitable courses to address 
those gaps.  
• The system should organize the recommendations into a logical learning path from 
foundational to advanced courses. 
Task 4 – Evaluation, Personalization & User Application 
• Evaluate the quality of course recommendations, skill-gap analysis and learning paths 
using representative student queries.  
• The solution should include a simple user interface through which students can enter 
learning goals and view recommendations, prerequisites, skill gaps and learning paths. 
• Feedback should be captured to support improvement of recommendations. 
Task 5 – Architecture, Documentation & Demonstration 
• Provide the complete technical documentation and demonstrate the working solution. 
• The architecture should clearly show the data-to-recommendation flow, while the 
design documentation should explain important technical decisions and trade-offs.  
• The executable implementation and README should allow another user to set up and 
run the solution. 
 
Deliverables
